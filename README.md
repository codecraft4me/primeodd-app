# PrimeOdd Android app (Kotlin + Jetpack Compose)
Talks to https://primeodd.store/api.php (upload the updated website zip first).

Build:
1. Install Android Studio (free). File > Open > this folder. Accept "Trust project" and let Gradle sync.
2. Run on a phone (USB debugging) or emulator with the green Run button.
3. APK for sharing: Build > Build Bundle(s)/APK(s) > Build APK(s). Play Store: Build > Generate Signed Bundle (AAB).
